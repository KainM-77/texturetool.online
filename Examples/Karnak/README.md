# Karnak examples (not MIT)

Nine 64 px tiles cut from the Temple of Karnak textures of *Tomb Raider: The Last Revelation*
(Core Design, Eidos). **These files are not covered by this repository's MIT licence.** They are
Core Design / Eidos artwork, included so HD Look has real classic art to work on, in the same way
the community has used these textures in custom levels for years. If you are the rights holder and
want them removed, open an issue and they will be.

They are 64 px on purpose: HD Look makes a low-res tile look HD at the same tile size, so each
one is meant to be imported into a 256 px atlas and run through **Edit › HD Look**.

| file | use it for |
|---|---|
| `karnak-painted-*` | Painted ornament: a mosaic or a vase figure with colour fields and outlines. Try the **Painted** class. |
| `karnak-embossed-*` | Relief painted onto a flat face: figures and murals. Try **Relief**. |
| `karnak-carved-*` | Hieroglyphs cut into stone. Try **Relief** and compare with **Built**. |
