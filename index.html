3️⃣ Export Atlas + Material Maps
⚠️ Height (parallax) maps are GPU-expensive in Tomb Engine. Prefer applying height to individual textures rather than a whole atlas, so you can measure the performance impact per texture and drop it where it isn’t worth the cost.
📐 Every map atlas must share the same dimensions. Texturetool guarantees this automatically when you export all maps together here. But if you export maps in separate passes — e.g. just the normal map now, other maps elsewhere or later — make sure the tile size and layout match every time, or Tomb Engine will throw an error and not load your material maps!

📐 Anchored Transition — Tile → Tile
The border between the two textures is a chain of anchors. Start from a preset, then drag anchors to bend the border, drag the line itself to slide the whole border across, click empty space to add an anchor, or right-click an anchor to remove it. Overlay (B) fills one side.

🏔️ Height Transition — Tile → Tile
Drive the blend by a height map instead of a drawn line: the overlay settles into the low ground (mortar joints, cracks) or caps the high ground (stones poking through). Works best on textures with real relief — e.g. cobble flooring.

🗺️ Transition Grid — Tile → Tile
Design one continuous A→B border across a whole wall, then slice it into tiles. Set the grid size, drag the anchors (drag the line itself to move the whole border, click empty space to add, right-click to remove). Scroll the wheel or middle-click an anchor to cycle its smoothness (corner → smooth → rounder); the border curves smoothly through the anchors. It flows across cell edges so the tiles connect seamlessly. Add drops one transition tile per cell into the atlas.
Tool:
With a patch tool active, drag from a point to drop a circular patch of the overlay (scroll over one to resize, right-click to remove). Patches work on top of — or instead of — the boundary, so you can put a circle of texture inside any single cell.
🌿 Organic Transition — Tile → Tile
Scatter the overlay into the base as organic, noise-driven patches. Optionally brush a hint for where the overlay should land, then generate seeded variations. Keep “Edge-safe” on so patches never touch the tile border — that keeps neighbouring tiles seamless.
Click a preview to toggle it in/out of the export set.
🎞️ Animated Texture
Generate a procedural, seamlessly-looping animation (water, lava, clouds…). Each frame also tiles on its own. Pick a preset, tweak, and add the frames to the atlas as a group. In Tomb Editor, select the frames as an animated range — or use Single seamless tile for UV-rotate.
💡 This preset glows — enable the Emissive export map (and set the matching material) so it lights up in-engine.
Click the bar to add a stop · drag a handle to move it · click a handle to edit its colour & alpha.
Evens out the noise so a gradient uses all its colours (best for Rainbow / Aurora). Relaxes contrast as it rises.
Bakes a per-frame emissive map so the texture lights up in the dark. Each frame's glow is derived from that frame, so it animates with the motion. Ships an Emissive atlas aligned to the animation.
Pulse dims the glow on a sine over the loop (seamless). Depth 0% = steady, 100% = fully off at the trough. Combines with the per-frame motion.
🎚 Adjust Colours — Tile
Non-destructive colour grade for the whole tile. Handy for rebalancing presets that blow out, or matching a texture to a level's mood.
🖌 Recolor — Tile from Tile
Samples the colour palette of the reference tile and shifts this tile's colours toward it (mean/standard-deviation transfer). Adjust the strength and fine-tune below.
☀ De-light — Tile
Flatten baked lighting so the texture reacts to Tomb Engine's dynamic lights. De-light the whole texture, or paint over a single baked shadow and inpaint it away from the surrounding texture.

🧩 Wang Set — Tile → Tile
Generates an edge set so the overlay terrain connects on every side. Pick how the tiles are arranged in the atlas below — a readable grid makes them easy to place in the editor. Tiles inherit materials from the two sources.
🧱 Borders & Corners — Tile + trim Tile
🪞 Origami mode — one texture only. The trim is the same texture rotated so its detail runs parallel to each edge and folds through the corners, so a ridge/plank texture reads as a continuous concentric frame.
Builds a reusable border tile set: the trim texture runs along the boundary of areas filled with the base texture. Place the tiles in the editor like a frame — edges, corners and fill all connect. Click any slot in the preview to change how it's made (own mask → rotated ↻ → mirrored ↔/↕ → an atlas tile 🖼) — handy when baked lighting makes a rotated edge look wrong. Tiles inherit materials from the two sources and stay editable (change a source tile and the set follows).
Rotates the trim texture along vertical borders (mitred corners).
✨ Generate Variations — Tile
Creates jittered copies (hue / brightness / saturation / contrast / grain / rotation / wrap shift) appended to the atlas — handy for breaking up obvious tiling repetition. Same seed reproduces the same set.
🪞 Origami Frame — Tile
Folds the texture into a concentric frame — a ridge or stripe texture becomes nested rings, as if the strip were folded around all four edges. The fold is symmetric and seams continuously through the corners.
🏗️ Build Pattern — Tile
Arranges this texture into a built surface — brick, coursed / cobbled stone, tile, herringbone, planks, a plank floor, shingles or pipes — by laying it into cells split by recessed joints, each cell a jittered sample so it doesn't read as repeats. The result is a fresh, seamlessly tiling tile; the dark joints become real depth in the material maps.
